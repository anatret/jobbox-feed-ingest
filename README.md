# Jobbox: сборщик объявлений

Раз в 30 минут читает новые сообщения групп из `sources.json`,
разбирает объявления о работе (`prompt.md`) и добавляет их в ленту Jobbox.

Запуск задаёт база Jobbox (pg_cron → workflow_dispatch). Ключи хранятся в секретах
репозитория. В лог пишутся только цифры, подробности — в базе.

## Меняете разбор?

Тот же разбор есть в приложении — функция `submit-job-ad` в jobboxv3
(`supabase/functions/_shared/feed_ad.ts`, `feed_prompt.md`). Здесь источник правды:
меняете `ingest.py` или `prompt.md` — переносите туда по шагам из `CLAUDE.md` jobboxv3
и проверяете `python tool/feed_sync_check.py` там же.

Репозиторий публичный: не выводить в лог тексты объявлений, телефоны, названия.
